# Advanced-calculator-
Этот калькулятор лучше чем все остальные.
Он может не только выполнять арифметические операции, он также может помогать переводить какую-либо единицу в нужную единицу счисления.
# ТЗ:
1. Сделать структуру кальулятора
2. Сделать кнопки для вычисления основных математических примеров
3. Сделать дополнительное окно для других мат. вычислений и сделать рабочие кнопки
4. Сделать окно для перевода в нужную единицу счисления
5. Добавить эти самые единицы
